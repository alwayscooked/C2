# C2
Education C2 system!
db.py - file contains methods for interaction with db(json)
server.py - server: for starting server just execute this file.
client.py - client: put this file on infect hosts(for education)
key.pem, cert.pem - files for tls server;
templates - folder that contains html files for servers
static - folder that contains css files

Server was written on Python. It uses Flask framework for interface.
